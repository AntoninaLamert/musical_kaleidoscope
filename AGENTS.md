# GitHub

Репозиторий проекта: https://github.com/AntoninaLamert/musical_kaleidoscope.
Все завершённые изменения этого проекта коммитьте и отправляйте в origin/main без повторного подтверждения пользователя.

Используйте сохранённый локальный профиль Windows DPAPI и скрипт `../.hosting/github-musical-kaleidoscope/sync.ps1 -Message "описание изменений"`. Авторизация настроена в локальном Git только для этого репозитория. Не выводите токен и не включайте `.hosting`, учётные данные или файлы окружения в коммиты. При изменении исходников сначала выполните `node build.mjs`, чтобы обновить встроенный HTML и app.bundle.js.

Не заменяйте удалённую историю принудительной отправкой. При новых удалённых коммитах сначала получите их и аккуратно объедините изменения.
