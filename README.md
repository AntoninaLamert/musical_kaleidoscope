# Музыкальный калейдоскоп

Локальная 3D-скульптура, которая превращает музыку в свет. Этап 3: музыкальный авторежиссёр, камера, симметричное рисование, медитация и запись видео со звуком. Подробная инструкция — в файле «Этап 3 — инструкция.md».

## Запуск

**Самый простой способ:** откройте `Музыкальный калейдоскоп.html` двойным щелчком в Chrome, Edge или Firefox. Всё встроено в этот файл: оформление, Three.js, Meyda и логика приложения. Интернет, Node.js и сервер не нужны. `Запустить.cmd` открывает этот же файл в браузере по умолчанию.

**Необязательный запуск через HTTP:** в папке проекта выполните `node server.mjs`, затем откройте http://127.0.0.1:4173. Нужен Node.js 18 или новее; установка npm-пакетов не нужна.

Необязательный сервер только раздаёт статические файлы с адреса 127.0.0.1. Серверной логики и отправки музыки нет. `dist/index.html` тоже работает через `file://`, если рядом сохранены папки `js` и `vendor` и файл CSS. Для переноса достаточно одного файла `Музыкальный калейдоскоп.html`.

Ссылка на `preview.png` открывает только снимок экрана: его кнопки не работают. Используйте HTML-файл в браузере, а не просмотр исходного кода внутри редактора.

После изменения исходных модулей выполните `node build.mjs`: он обновляет `dist/js/app.bundle.js` и автономный HTML без сторонних инструментов сборки. Исходники по-прежнему разделены по назначению.

## Управление

- «Загрузить mp3» или перетаскивание: добавить один или несколько треков. Нажмите ▶ для старта; пробел включает паузу и воспроизведение.
- Кнопки слева выбирают одну из шести форм. Можно выбирать новую форму во время превращения.
- Панель «Калейдоскоп» выбирает фон: «Мандала», «Кристаллы», «Космос», «Цветы», «Лазерное шоу». Это разные геометрические узоры, а не только разные цвета. Переход длится 2,6 секунды; повторный выбор во время перехода плавно продолжает текущую смесь.
- «Авто» включён по умолчанию и управляет всей сценой. Подстраивает атмосферу и движения под звучание, меняет формы и стили примерно раз в 21–28 секунд с ожиданием акцента до трёх секунд. Ручной выбор формы или стиля выключает авторежиссёра.
- «Симметрия» задаёт 4–24 зеркальных сектора с шагом 2, «Интенсивность» — яркость и насыщенность фона. На узком экране панель переносится под сцену; на невысоком настольном экране управление уплотняется, чтобы оставалось место для проигрывателя.
- Перетаскивайте скульптуру мышью или пальцем. Автовращение мягко возвращается после отпускания.
- Предыдущий/следующий трек и выбор в плейлисте запускают перекрёстное затухание до 2,5 секунд. Кнопки смены трека на время перехода блокируются. Пауза сохраняет положение перехода. Перемотка завершает переход на выбранном треке.
- Треки автоматически идут по кругу; один трек тоже повторяется. Очень короткие треки имеют сокращённый переход. Ползунок управляет громкостью; кнопка справа вверху включает полный экран.
- Музыка хранится только в памяти текущей страницы через blob URL. После обновления страницы её нужно выбрать заново.
- После загрузки начинается предварительный анализ треков. Если он ещё не готов при нажатии ▶, существующая строка плеера показывает «Анализ ритма композиции…». Анимация и интерфейс продолжают работать. Повторное воспроизведение использует готовую карту без нового анализа.

## Устройство проекта

- `dist/index.html`, `dist/style.css` — интерфейс, мобильная компоновка.
- `dist/js/audio-player.js` — два HTMLAudioElement, граф Web Audio, плейлист и crossfade. Воспроизведение начинается только после готовности карты соответствующего трека. При переходе преобладающий трек определяется по его предварительно рассчитанной RMS-громкости и коэффициенту затухания; передача управления происходит однократно с гистерезисом, чтобы два трека не посылали конфликтующие импульсы.
- `dist/js/rhythm-analysis.js` — собственный алгоритм без дополнительных библиотек. MP3 декодируется Web Audio API в AudioBuffer с частотой 22,05 кГц, затем каналы анализируются в Blob Worker. Если Worker недоступен, тот же алгоритм работает небольшими порциями с уступкой интерфейсу. Очередь ограничивает обработку одним файлом; выбранный трек получает приоритет. После анализа PCM освобождается, в памяти остаются карта событий и компактная огибающая громкости.
- Детектор выделяет 40–200 Гц двумя фильтрами Butterworth, считает 20-мс RMS-окна с шагом около 5 мс, находит положительные изменения логарифма энергии с адаптивным порогом, отслеживает начало атаки и объединяет повторные срабатывания в пределах 160 мс. Энергии каналов усредняются без взаимного подавления противофазных сигналов.
- Автокорреляция анализирует до 180 секунд, распределённых по композиции; оцениваются также половинный/двойной темп. Взвешенная фазовая гистограмма и уточнение периода по линейной регрессии уменьшают накопленное расхождение сетки. Согласованность дополнительно проверяется по 12-секундным участкам. Сетка хранится как метаданные: **импульсы всегда запускаются реальными обнаруженными атаками**, а не пустыми делениями сетки. При нестабильном темпе используются надёжные события, BPM остаётся неопределённым.
- `dist/js/rhythm-clock.js` — единственный источник ритмических событий. Использует `HTMLAudioElement.currentTime`, курсор карты и восемь переиспользуемых слотов. Каждое событие обрабатывается один раз; при перемотке, повторе и смене преобладающего трека сбрасываются старые эффекты. Возраст эффектов тоже рассчитывается по аудиопозиции. Пауза замораживает ритмические эффекты; пропущенные во вкладке в фоне удары не воспроизводятся очередью.
- `dist/js/audio-analysis.js` — Meyda: RMS, спектр, диапазоны и сглаживание атмосферы. Meyda больше не определяет удары и не изменяет общий масштаб.
- `MusicSignal` — единый контракт визуализации: `loudness`, `bass`, `mids`, `highs`, `energy`, `beat`, `beatId`, `phase`, `bpm`, `active`; `spectrum` содержит 24 сглаженные полосы. `impulses` — фиксированный пул событий с полями `time`, `age`, `strength`, `confidence`, `id`. Вспышки скульптуры, масштаб, волны и выбросы частиц используют одни и те же метки. Фон использует события только для выбора момента автоматической смены стиля: его масштаб и яркость больше не пульсируют на ударах.
- `dist/js/shapes.js` — шесть совместимых параметрических наборов вершин. Морфинг на GPU, включая изменение топологии при появлении отверстия тора. Длительность 2,2 секунды; при прерывании фиксируется текущая промежуточная форма. Промежуточные поверхности могут пересекаться — для прозрачной энергетической скульптуры это часть эффекта.
- `dist/js/visualizer.js` — шейдерные деформации и переливы, светящиеся грани, внутренняя оболочка, частицы, орбиты, дымка, bloom в отдельном уменьшенном буфере. Геометрия и материалы переиспользуются, текстура ореола создаётся один раз.
- `dist/js/kaleidoscope.js` — независимая перспективная камера, переходы 2,6 секунды, автоматическая смена, палитры атмосферы и уменьшенные фоновые буферы. `kaleido-worlds.js` содержит пять постоянных 3D-сцен: ажурные орнаменты на разных расстояниях, инстансированные стеклянные осколки, звёзды и туманности с отдельной спиральной галактикой, изогнутые лепестки с пыльцой, лазерные веера и тоннель. Камера медленно смещается в стороны, создавая параллакс, без ритмического приближения.
- `dist/js/kaleido-shaders.js` зеркально отражает изображение одного сектора на GPU. По визуальным примерам добавлены заполненные розетки с ажурными контурами, цветная треугольная мозаика и органические цветочные орнаменты на трёх масштабах. Центр перспективы совпадает с центром скульптуры. Логарифмические радиальные координаты уменьшают элементы орнамента к центру: их видимый размер пропорционален расстоянию от центра. Угловые расстояния сохраняются в радианах, поэтому изменение числа секторов не сжимает исходные элементы в узкие полосы. Цвета поддерживаются медленно сглаженным сигналом Meyda; фон не получает огибающую удара. Общая композиция приглушена за скульптурой.
- Все тяжёлые фоновые проходы выполняются в адаптивно уменьшенных буферах шириной до 1440 пикселей. Рисуются только активные стили и участники перехода; неактивные буферы уменьшаются до 1×1. Геометрия и материалы переиспользуются, при закрытии освобождаются. Свечение скульптуры рассчитывается отдельно: её вспышки bloom больше не осветляют весь калейдоскоп.
- `dist/js/atmosphere.js` — два постоянных слоя инстансированной дымки и мягких лучей в трёхмерном пространстве перед скульптурой и за ней. Периодическая текстура шума 128×128 создаётся один раз. Пыль, искры, орбиты и волны плавно принимают цвета текущей смеси стилей. На минимальном качестве сохраняются оба плана, уменьшается число пятен дымки. Ресурсы освобождаются при закрытии страницы. Для аддитивных прозрачных оболочек скульптуры отключён лишний отдельный проход обратных граней: обе стороны рисуются за один проход, формы и морфинг сохранены.
- `dist/js/app.js` — интерфейс и основной цикл.
- `dist/vendor/` — Three.js 0.170.0 и Meyda 5.6.3, лицензии рядом. Никаких CDN-запросов при работе.

Разрешение ограничено коэффициентом 1,6 даже на Retina. При устойчивой частоте ниже 38 кадров/с качество постепенно снижается: разрешение, bloom, число частиц и внутренняя оболочка. Во вкладке в фоне графика не отрисовывается. Системная настройка уменьшения движения замедляет вращение. Браузер и энергосбережение ОС могут приостанавливать фоновые таймеры: на переднем плане переходы наиболее точны.

Основной акцент — пульсация самой скульптуры. На сильном ударе она увеличивается до 24%: атака около 16 мс, короткий пик до 50 мс от начала удара и плавный возврат с постоянной времени 140 мс. Сила для масштаба сжимается квадратным корнем: средние удары тоже хорошо видны, слабые остаются мягче сильных. Грани подсвечиваются вместе с движением фигуры. Волны служат только дополнением: тонкие, с низкой яркостью, небольшим радиусом и временем жизни до 0,55 с. Выбросы частиц слабее и затухают быстрее; дополнительная вспышка фонового ореола и bloom уменьшена. Восемь волн и восемь наборов частиц создаются один раз; новые удары могут перекрывать затухание предыдущих. Масштаб берётся из максимума огибающих, поэтому частые удары не раздувают объект. Все эффекты используют прежние аудиометки; независимой синусоидальной пульсации нет.

Синхронизация не накапливает ошибку: каждый кадр использует реальную позицию аудио. Точность распознавания зависит от музыки, а момент отображения — от частоты кадров и задержки вывода устройства; это не обещание сэмпловой точности на любых устройствах. До загрузки музыки работают спокойная атмосфера и непрерывная анимация калейдоскопа без ритмических вспышек. Ошибки WebGL и чтения файлов выводятся в интерфейсе. Шесть форм, морфинг и музыкальный проигрыватель сохранены.

Документация библиотек: [Three.js BufferGeometry](https://threejs.org/docs/pages/BufferGeometry), [Meyda Web Audio](https://meyda.js.org/guides/online-web-audio), [Meyda audio features](https://meyda.js.org/audio-features).

## Исправления 2.3

Canvas занимает отдельную центральную область между боковыми панелями; на мобильном экране — между заголовком и кнопками форм. Фон не рисуется под управлением. Центры скульптуры и калейдоскопа совпадают. Симметрия меняется коротким перекрёстным переходом между двумя целыми чётными числами секторов, без промежуточной дробной симметрии. Интенсивность влияет только на цвет и яркость.

## Модули этапа 3

`director.js` — общий музыкальный авторежиссёр; `artist.js` — одна текстура штрихов и ввод мышью/пальцем; `show-recorder.js` — запись готового Canvas и существующего аудиомикса. Полная инструкция, горячие клавиши и ограничения записи описаны в «Этап 3 — инструкция.md».
